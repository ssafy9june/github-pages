01

Purpose

What the application does

Finds expense notices

It reads relevant transaction notification emails from the owner's Gmail account to identify expense information such as the transaction date, merchant, and amount.

Organizes personal records

The extracted information is converted into expense records and stored on the owner's private, self-managed server for personal budgeting and review.

Remains non-public

There is no public sign-up, no service offered to third parties, and no public access to the owner's email or financial records.

02

Google user data

Limited, read-only access

Requested permission

https://www.googleapis.com/auth/gmail.readonly

The application uses this permission only to locate and process emails needed for its expense-tracking function. It cannot send, edit, or delete Gmail messages. Google user data is not sold, used for advertising, or shared with third parties.
