Privacy Policy

This policy explains how June Expense Tracker accesses, uses, stores, and shares Google user data.

Private, non-public service

June Expense Tracker is operated exclusively for its owner's private personal project. The application itself is available only on the owner's non-public internal network and is not offered to external users. Only this informational website is public.

1. Google data the application accesses

The application requests the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly). It accesses relevant transaction notification emails in the owner's Gmail account, including message content needed to identify expense details such as transaction date, merchant, and amount.

2. How Google data is used

Google user data is used only to identify expense notifications and create personal expense records for the owner. The application does not use Gmail data for advertising, profiling, credit decisions, or any purpose unrelated to personal expense tracking.

3. Data storage and protection

Extracted expense records and OAuth credentials are stored on a private, owner-controlled server that is not publicly accessible. Access is limited to the application owner. Reasonable technical safeguards are used to prevent unauthorized access, disclosure, or alteration.

4. Data sharing and transfer

Google user data is not sold, rented, disclosed, or transferred to third parties. No Google user data is used to serve advertisements or train generalized artificial intelligence or machine-learning models.

5. Data retention and deletion

Data is retained only for as long as the owner uses the application or needs the personal expense records. The owner can delete stored records and OAuth credentials from the private server at any time. Google access can also be revoked from the Google Account security settings, after which the application can no longer access Gmail.

6. Limited Use disclosure

June Expense Tracker's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Changes to this policy

This policy will be updated if the application's handling of Google user data changes. The effective date at the top of this page will show the latest revision.

8. Contact

Privacy and support questions may be sent to the developer contact address shown on the application's Google OAuth consent screen.
