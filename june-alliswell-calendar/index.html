June Alliswell Calendar helps its owner manage personal schedules and calendar events by integrating Google Calendar with Alliswell in a private setup.

Private-use notice

This application is used solely by its owner for a private personal project (Alliswell). The actual service runs only on the owner's local environment and private Tailscale network, and is never exposed or offered to external users. This public page exists only to provide Google OAuth application information and privacy disclosures.

이 애플리케이션(Alliswell 캘린더 연동)은 소유자 개인의 프라이빗 프로젝트를 위해서만 사용됩니다. 실제 서비스는 소유자의 로컬 환경 및 테일스케일(Tailscale) 기반의 비공개 내부 네트워크에서만 운영되며, 외부에 전혀 공개되지 않고 제3자에게 제공되지 않습니다. 이 공개 페이지는 Google OAuth 앱 정보와 개인정보 처리 내용을 안내하기 위해서만 제공됩니다.

01

Purpose

What the application does

Syncs personal calendar

It connects to the owner's Google Calendar account to view and synchronize personal schedules, events, and agenda items within Alliswell.

Local & Tailscale private hosting

The service runs strictly on the owner's local machine and secure Tailscale private network. Calendar data remains completely within the owner's self-managed environment.

Remains non-public

There is no public sign-up, no service offered to third parties, and no public access to the owner's calendar or personal information.

02

Google user data

Limited, private access

Requested permissions

https://www.googleapis.com/auth/calendar.readonly
https://www.googleapis.com/auth/calendar.events

The application uses these permissions only to view and synchronize calendar events needed for personal schedule management in Alliswell. It operates exclusively within the owner's private local environment via Tailscale. Google user data is not sold, used for advertising, or shared with third parties.
