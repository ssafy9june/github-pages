rclone-audiobook-june is a personal Google OAuth configuration for rclone, used to access and manage the owner's audiobook files in Google Drive.

Private-use notice

This project is for its owner's personal use. The rclone program runs in the owner's own environment. This public website provides OAuth application information and privacy disclosures only.

소유자 개인의 오디오북 파일을 Google Drive와 연동하기 위한 rclone OAuth 설정입니다. rclone은 소유자의 환경에서 실행되며, 이 공개 웹사이트는 OAuth 앱 소개와 개인정보 처리 내용을 안내합니다.

01

Purpose

A personal audiobook workflow

Google Drive connection

Google OAuth authorizes rclone to access the owner's Drive account for personal audiobook file management.

Owner-controlled access

File access and transfers take place through the owner's rclone installation, within the permissions granted during authorization.

Personal use

This project does not offer public registration or public access to the owner's audiobook files or Google account.

02

Google user data

Access through Google OAuth

Google Drive permissions

The requested access is determined by the owner's rclone configuration and displayed on Google's consent screen.

Drive file names, folder information, file metadata, and audiobook contents are used for the owner's file workflow. Read-only access allows listing and downloading; broader Drive access also permits uploading, organizing, or deleting files when the owner requests those operations. Data is not used for advertising or sold to third parties.
