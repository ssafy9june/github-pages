Privacy Policy

How rclone-audiobook-june handles Google user data for its owner's personal audiobook workflow.

Personal use

This project is a personal Google OAuth configuration used with rclone. This public informational website does not connect to Google Drive or receive OAuth tokens or audiobook files.

이 프로젝트는 개인용 rclone Google OAuth 설정입니다. 이 안내 웹사이트에서는 Google Drive에 접속하거나 OAuth 토큰 및 오디오북 파일을 수신하지 않습니다.

1. Data accessed and permissions

The rclone installation accesses Google Drive file names, folder structure, file identifiers, sizes, modification times, and file contents needed to manage the owner's audiobook files. Its authorized reach depends on the Drive permissions selected in rclone and approved on Google's consent screen; a broad Drive scope can authorize access beyond the audiobook folder.

Read-only authorization permits listing and downloading files. If the owner grants full Drive access, rclone can also upload, rename, move, or delete files at the owner's direction. This website itself requests no OAuth permissions.

2. How data is used

Google Drive data is used only to access, transfer, and organize the owner's personal audiobook collection through rclone. It is not used for advertising, marketing, profiling, or training generalized artificial intelligence or machine-learning models.

3. Storage and protection

Files remain in the owner's Google Drive and in any destinations the owner selects for local copies or transfers. OAuth credentials and tokens are handled by rclone in the owner's environment. The owner is responsible for protecting the rclone configuration, limiting access to the host system, and securing any stored copies. Credentials and file contents are not stored in this public website or its source repository.

4. Sharing

This project does not sell, rent, or distribute Google user data to third parties. Transfers are limited to the owner's chosen destinations for the personal audiobook workflow. This website does not publish the owner's Drive contents.

5. Retention, deletion, and revocation

The owner controls how long to keep files, downloaded copies, caches, and rclone credentials, and can remove them from their respective storage locations. Authorization can be revoked through Google Account connections. Revoking authorization prevents future authorized access; it does not delete previously downloaded files or other stored copies.

6. Google API Services User Data Policy

This project's use of information obtained through Google APIs, including any transfer of that information, will comply with the Google API Services User Data Policy and its Limited Use requirements.

7. Changes and contact

This policy will be updated when the project's data handling changes. The effective date identifies the latest revision. Privacy or support inquiries may be sent to the developer contact address shown on the project's Google OAuth consent screen.
